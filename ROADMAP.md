# Roadmap — NoTweet

## Done ✅

- [x] Automatic reply loop with human-like behavior simulation
- [x] Character-by-character typing with random delays
- [x] Auto-submit after typing
- [x] Auto-like before replying
- [x] Reply-back to people who reply to your own tweets
- [x] Configurable daily reply limits
- [x] Random delay between replies (min/max in minutes)
- [x] 7-day tweet memory (never replies to the same tweet twice)
- [x] Filter by keywords and specific accounts
- [x] Full side panel UI with tabs
- [x] First reply waits the configured delay — no immediate fire on Start
- [x] Proxy support to hide Claude API key

---

## In Progress 🚧

- [ ] Weekly / monthly stats dashboard
- [ ] Choose Claude model from settings (Haiku / Sonnet / Opus)
- [ ] Notification when daily limit is reached

---

## Planned 📋

### Near term
- [ ] Multi-account support (run on more than one Twitter account)
- [ ] Scheduled hours (e.g. only run 8pm–midnight)
- [ ] Language filter (e.g. only reply to English tweets)

### Long term
- [ ] External web dashboard for monitoring performance
- [ ] Support for other platforms (LinkedIn, Threads)
- [ ] Reply performance analytics (likes and replies received on bot replies)
