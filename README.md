# NoTweet

إضافة كروم تقوم تلقائياً بالرد على التغريدات في مجتمعات تويتر/X باستخدام الذكاء الاصطناعي Claude.

## ماذا تفعل؟

- تتصفح الفيد مثل إنسان حقيقي
- تختار التغريدات من المجتمعات التي تهتم بها
- تولّد ردوداً طبيعية وقصيرة عبر Claude AI
- تكتب الرد وترسله تلقائياً
- تتذكر التغريدات التي ردّت عليها (لمدة 7 أيام)
- تحترم الحدود اليومية والوقت بين كل رد

---

## التثبيت

### 1. بناء الإضافة

```bash
git clone <repo-url>
cd notweet
npm install
npm run build
```

### 2. تحميلها على كروم

1. افتح `chrome://extensions`
2. فعّل **Developer mode** من الزاوية العلوية
3. اضغط **Load unpacked** واختر مجلد `dist/`

### 3. الإعداد

افتح لوحة الإضافة واذهب إلى **Settings**:

| الإعداد | الوصف |
|---------|-------|
| Claude API Key | مفتاحك من [console.anthropic.com](https://console.anthropic.com) |
| My Handle | معرّفك على تويتر بدون @ |
| Keywords | ردّ فقط على تغريدات تحتوي هذه الكلمات (فارغ = الكل) |
| Accounts | ردّ فقط على حسابات معيّنة (فارغ = الكل) |
| Daily limit | أقصى عدد ردود يومياً |
| Min / Max delay | الوقت بالدقائق بين كل رد |
| Auto-submit | إرسال الرد تلقائياً بعد الكتابة |
| Auto-like | الإعجاب بالتغريدة قبل الرد |

### 4. التشغيل

انتقل إلى أي مجتمع على تويتر/X ← افتح الإضافة ← اضغط **Start**.

---

## التقنيات المستخدمة

- Chrome MV3 — Service Worker + Content Script
- React 18 — واجهة مدمجة داخل Shadow DOM
- Vite — أداة البناء
- Claude API — توليد الردود

---

## التطوير

```bash
npm run build    # بناء كامل
npm run dev      # وضع المراقبة التلقائية
```

بعد كل بناء، افتح `chrome://extensions` واضغط أيقونة التحديث على بطاقة NoTweet.
